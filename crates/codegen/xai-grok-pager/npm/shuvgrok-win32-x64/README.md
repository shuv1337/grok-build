# @shuv1337/shuvgrok-win32-x64

Platform-specific binary for [`@shuv1337/shuvgrok`](https://www.npmjs.com/package/@shuv1337/shuvgrok) on win32-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @shuv1337/shuvgrok
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.

Source: [shuv1337/grok-build](https://github.com/shuv1337/grok-build)
